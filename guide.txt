2. End-to-End Methodology & Anti-Leakage Protocol
Data leakage is the most critical methodological error in machine learning text classification. To guarantee valid,
unbiased generalization performance, the project enforces a strict partitioned pipeline:
Raw UCI SMS Dataset (5,572 rows) -> Clean & Deduplicate (5,169 distinct rows)
↓
Stratified 80/20 Train/Test Split (Train: 4,135 [3,613 Ham, 522 Spam] | Test: 1,034 [903 Ham, 131
Spam])
↓
Fit TfidfVectorizer STRICTLY on Training Text Only (Prevent test vocabulary leakage)
↓
Transform Training and Test Sets using Fitted Vectorizer
↓
Apply SMOTE ONLY to Training Features (Synthesize minority samples -> 3,613 Ham : 3,613 Spam)
↓
Train Machine Learning Classifiers (Logistic Regression with SMOTE, Multinomial Naive Bayes)
↓

Core Pipeline Principles: Methodological Rules (update.md Section 9):
1. Never fit vectorizers across the full corpus before splitting; vocabulary frequencies must not leak from test to train.
2. Never apply SMOTE or oversampling to the held-out test split. The test set must reflect true operational class
prevalence (~12.6% spam).
3. Evaluate all competing models on the identical test split to ensure fair comparative benchmarking.

3. Model Architectures & Algorithmic Foundations
Logistic Regression with SMOTE (Primary Linear Model)
Logistic Regression models log-odds using the sigmoid function: P(Y=1|X) = 1 / (1 + exp(-beta^T X)). High-dimensional
TF-IDF matrices (5,000 terms) are typically linearly separable. In imbalanced datasets, the linear hyperplane biases
toward the majority class, producing low spam recall (78.63%) and 28 false negatives. By applying SMOTE to the
training features, the decision margin is shifted, boosting spam recall to 90.08% and reducing false negatives to 13.

Multinomial Naive Bayes & The SMOTE Distortion Effect
Multinomial Naive Bayes estimates posterior class likelihoods using Bayes' Theorem with Laplace smoothing
(alpha=0.2). Crucially, the professor requested an analysis of SMOTE compatibility with Naive Bayes: When SMOTE is
applied, it interpolates synthetic continuous values between feature points, violating the discrete integer word frequency
assumption of the multinomial distribution. Furthermore, SMOTE artificially enforces a uniform class prior P(Spam) =
0.50, causing the model to over-predict spam on the authentic test distribution. As a result, standard MNB achieves
98.26% precision with only 2 false positives, whereas applying SMOTE degrades MNB precision. This highlights a key
pedagogical takeaway: geometric classifiers benefit from SMOTE, while generative Bayesian models prefer natural
frequencies.

Deep Contextual Transformers: DistilBERT & DistilRoBERTa
Unlike bag-of-words representations that discard syntax and word order, transformer architectures leverage multi-head
self-attention to analyze full bidirectional context. We fine-tuned two state-of-the-art distilled models: 1) DistilBERT: A 6layer architecture retaining 97% of BERT's language understanding with 40% fewer parameters (66M) and 60% faster
execution. 2) DistilRoBERTa: A distilled RoBERTa architecture (82M parameters) pre-trained with dynamic masking on
larger corpora, yielding enhanced sensitivity to subtle phrasing.

8. Starter Code Blueprint: Anti-Leakage SMOTE Pipeline
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix
from imblearn.over_sampling import SMOTE
# 1. Ingestion & Cleaning
df = pd.read_csv('data/SMSSpamCollection', sep='\t', header=None, names=['label',
'text']).drop_duplicates()
df['y'] = df['label'].map({'ham': 0, 'spam': 1})
# 2. Stratified Split (BEFORE vectorization)
X_train, X_test, y_train, y_test = train_test_split(
df['text'], df['y'], test_size=0.20, random_state=42, stratify=df['y']
)
# 3. Fit TF-IDF on Training Data Only
tfidf = TfidfVectorizer(max_features=5000, stop_words='english', ngram_range=(1,2))
X_train_vec = tfidf.fit_transform(X_train)
X_test_vec = tfidf.transform(X_test)
# 4. Apply SMOTE to Training Features Only
smote = SMOTE(random_state=42)
X_train_smote, y_train_smote = smote.fit_resample(X_train_vec, y_train)
# 5. Train Model & Evaluate on Untouched Test Set
model = LogisticRegression(C=2.0, max_iter=1000, random_state=42)
model.fit(X_train_smote, y_train_smote)
y_pred = model.predict(X_test_vec)
print(classification_report(y_test, y_pred, target_names=['Ham', 'Spam']))
